Build the "Nameplate Forge" app described in plan.md (in this folder). Read plan.md fully before writing any code — it is the spec.

WHAT IT IS
A free, browser-only single-page app (deployed on GitHub Pages) that generates 3D-printable nameplates that wrap the sloped rim of wargaming miniature bases. The 3D viewer is the centrepiece: the user always sees the plate on the actual base and can orbit around it. When done, they download an STL.

DECISIONS ALREADY MADE (open questions in plan.md §11 — use these defaults unless I say otherwise)
- Framework: React 18 + TypeScript (strict) + Vite, three.js via @react-three/fiber + drei, zustand for state.
- Geometry: manifold-3d (WASM) running in a Web Worker via Comlink; opentype.js for fonts. Follow the cone-unrolling math in plan.md §5.3 exactly (text laid out glyph-by-glyph along an arc in the unrolled sector, then warped onto the frustum; MDF/vertical edge = cylinder special case).
- Printer default: resin (min feature 0.3 mm), with FDM (0.8 mm) as an option later.
- Scope for this session: glue-on plates only (no whole-base export yet).
- App name (final): "Nameplate Forge"; repo name (final): "nameplate-forge" (Vite base: '/nameplate-forge/'). Do not use "Warhammer" in the app name or ship any Games Workshop fonts/logos.
- Pin exact dependency versions.
